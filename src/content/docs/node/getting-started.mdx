フレームワークなどを使わず、あえてゼロからNode.jsプロジェクトを構築することで、Node.jsへの理解を深めようという試みのドキュメントです。

## プロジェクトフォルダの作成

プロジェクトルートとなるフォルダを作成し、Node.jsの初期設定をします。

<Steps>
    1.  任意の場所にプロジェクト用のフォルダを作成します。  
        これがプロジェクトルートフォルダになります。

    2.  ターミナルでプロジェクトフォルダを開き、以下のコマンドを実行します。
        ```zsh
        npm init --yes
        ```
        <Aside title="コマンドの意味">
            `init`は、プロジェクトフォルダを初期化するという命令です。
            これを実行すると、プロジェクト名やバージョンなどのいくつかの質問のあと、`package.json`が生成され、Node.jsのプロジェクトフォルダとして初期化されます。

            `--yes`（省略形：`-y`）はオプションで、質問を省略してすべてデフォルト値でプロジェクトフォルダを初期化します。
        </Aside>

    3. プロジェクトフォルダ内に`package.json`が生成されていれば完了です。
        <Aside title="package.jsonとは？">
            `package.json`は、プロジェクトの設定ファイルです。

            -   使用しているパッケージ
            -   使用できるコマンド

            などが記録されます。
            機能を追加していくと、このファイルが自動的に更新されていきます。
        </Aside>

</Steps>

## フォルダ構成の作成

開発資材を格納するためのフォルダを作成します。

<Steps>
    1.  プロジェクトルートに`src`フォルダを作成します。

    2.  `src`フォルダ内に、`index.html`や、`css`、`js`など、必要なファイルやフォルダを任意で追加します。

</Steps>
