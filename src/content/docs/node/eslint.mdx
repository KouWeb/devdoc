ESLintは、JavaScriptやTypeScriptを解析して問題を検出し、修正するためのツールです。

モダンなフロントエンド開発ではデファクトスタンダードとなっています。

## ESLintのインストール

ESLintをインストールします。

```zsh
npm install --save-dev eslint @eslint/js typescript-eslint
```

<Aside title="typescript-eslint">
    ESLintをTypeScriptに対応させるためのプラグインです。
</Aside>

## 設定ファイルの作成

プロジェクトルートに`eslint.config.js`を作成し、以下の設定をします。

```js
import eslint from "@eslint/js";
import tseslint from "typescript-eslint";

export default tseslint.config(
    eslint.configs.recommended,
    tseslint.configs.recommended
);
```

## typeフィールドの設定

`package.json`の`type`フィールドの設定をします。

```json
"type": "module",
```

<Aside title='"type": "module"'>
    Nodeプロジェクト内の`.js`ファイルをES Modulesとして解釈させるための設定です。

    設定ファイル内で`import`文が使用できるようになり、よりモダンでシンプルに設定できます。

</Aside>

## コマンドの登録

`package.json`にコマンドの登録します。

```json
"scripts": {
    "watch:ts": "tsc --watch",
    "watch:scss": "sass src/scss/style.scss src/css/style.css --no-source-map --watch",
    "watch:bs": "browser-sync start --server src --files 'src/**/*'",
    "watch": "run-p watch:ts watch:scss watch:bs",
    "lint": "eslint src/_ts/**/*.ts"
},
```

## 解析の実行

以下のコマンドで解析を実行します。

```zsh
npm run lint
```
