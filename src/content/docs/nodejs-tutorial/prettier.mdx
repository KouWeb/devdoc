Node.jsプロジェクトにPrettierを導入してコード整形を自動化します。

## インストールと設定

プロジェクトにPrettierをインストールし、基本設定を行います。

<Steps>
    1.  Prettierをインストールします。
        ```zsh
        npm install --save-dev prettier eslint-config-prettier
        ```
        <Aside title="eslint-config-prettier">
            ESLintが持つコード整形機能のルールと競合しないようにするためのパッケージです。
        </Aside>
    2.  Prettierの設定ファイルを作成します。  
        プロジェクトルートに`.prettierrc`を作成し、以下のような設定をします。
        ```json
        {
            "bracketSpacing": true,
            "printWidth": 9999,
            "proseWrap": "preserve",
            "semi": true,
            "singleQuote": true,
            "tabWidth": 4,
            "useTabs": true,
            "trailingComma": "es5"
        }
        ```
    3.  ESLintの設定にPrettierを追加します。  
        `eslint.config.js`に、以下のように追記します。
        ```js
        import eslint from "@eslint/js";
        import tseslint from "typescript-eslint";
        import prettier from "eslint-config-prettier";
        export default [
            eslint.configs.recommended,
            tseslint.configs.recommended,
            prettier
        ];
        ```

</Steps>

## コマンドの登録

`package.json`の`scripts`に以下のコマンドを登録します。

```json
"format": "prettier --write src/**/*.html src/ts/**/*.ts src/scss/**/*.scss"
```

## フォーマットの実行

以下のコマンドでフォーマットを実行します。

```zsh
npm run format
```

## Prettierの注意点

### セルフクロージングタグ

Prettierはセルフクロージングタグ（`<img>`、`<br>`など）の末尾に自動的に`/`を追加します。

整形前： `<img src="img.png">`  
整形後： `<img src="img.png" />`

HTML Living Standardでは、上記は全く同じものと解釈されるため問題ありません。

### 意図的な改行の削除

Prettierは、配列や関数の引数などで可読性のために意図的な改行を入れていても、それを無視して1行にまとめます。

整形前：

```js
const myArray = [
	12,
	34,
	56
];
```

整形後：

```js
const myArray = [12, 34, 56];
```

## Prettierを無効化する

Prettierがインストール済みのNode.jsプロジェクト内で、Prettierを無効化したい場合は、`.prettierignore`で設定してください。

以下は`src`ディレクトリ内の全てのコードに対してPrettierを無効化する例です。

```
src/*
```

配列やメソッドチェーンなど、コード内で部分的にピンポイントでPrettierを無効化したい場合は、`prettier-ignore`を使用します。

```ts
// prettier-ignore
const myArray1 = [
	12,
	34,
	56
];
// ↑無効化される。

const myArray2 = [12, 34, 56];
// ↑無効化されない。
```
